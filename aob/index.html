Aqualand Office Building

AOB-MEJ-ZZ-ZZ-M3-A-0001
  • Commercial office
  • Uniclass 2015
  • Schedules

A four storey office building with a lower ground plant level and roof plant in Austral, New South Wales. I modelled the geometry earlier; this project is about the information inside it. The rooms started with no departments and fifteen wrong names, and the IFC wrote every space as NOTDEFINED. It ends with all 62 rooms classified to Uniclass 2015, schedules on an ISO named sheet, an IFC4 file that passes both a schema check and a property check, and 48 fewer warnings.

01What was wrong

The room schedule held numbers and nothing else. No room had a department, 15 were named Room or misspelt, the project was still called NSW Office Building with number MEJ-001, and no door type carried a classification.

02What I decided

Four shared parameters in a Classification group: Uniclass SL number and description on rooms, Pr number and description on door types. Rooms renumbered by level, LG.01 to RF.01, renamed and given a department from an agreed table, each matched on its old number and checked against its area before writing. Where Uniclass has no answer I chose and logged one: the verandah takes SL_90_20_91 Terraces, and male and female WCs share SL_35_80_89 because Uniclass does not split by gender.

03What changed

The data now drives the drawings: a department colour scheme fills every room on six plans at 1:200.

IFC export and validation

IFC4 export validated for schema and property content

62/62
IfcSpaces carrying a Uniclass reference, a Department and a base quantity area

01What was wrong

In BIMcollab Zoom, space 03.10 read NOTDEFINED for both Predefined Type and Type Name. No room had an IFC Predefined Type, so Revit wrote one NOTDEFINED space type for all 62. The same check found IfcBuilding still named NSW Office Building, and CSI Uniformat riding along from Assembly Codes on 37 family types.

02What I decided

IFC4 Reference View with base quantities, common property sets, shared coordinates and Uniclass 2015 as the only classification. IFC Predefined Type set on every room from IfcSpaceTypeEnum: 59 INTERNAL and 3 verandahs EXTERNAL, with a new IsExternal parameter so Pset_SpaceCommon reads True on the verandahs. Assembly Codes cleared, building name and address corrected.

03What changed

Zero schema errors and zero EXPRESS rule violations in IfcOpenShell. Space 03.10 now reads INTERNAL, same GUID, same Uniclass code. Every count reconciled with Revit.

04What I caught

The first scripted export used the new parameter mapping. It dropped every property set, leaving Department and area on 0 of 62 spaces, and it still validated with 0 errors. I rejected it and exported again with the classic mapping. A clean schema report proves the file is well formed, nothing more.

Model health and sheet setup

Warning reduction and ISO 19650 title block

133→85
warnings, with every room area checked before and after

01What was wrong

133 warnings, 119 of them wall and room separation line overlaps. Section AA showed 130 cyan separation lines and level heads printing on top of each other. The schedule sheet sat on the Autodesk sample title block, with its logo and four empty ISO boxes.

02What I decided

Delete only the 48 separation lines lying on room bounding walls, behind a guard: compare every room area before and after, roll back if any changed by more than 0.05 m² or hit zero. A trial on the other 71 zeroed 36 rooms, so it was rolled back and those lines stay. For the sheet, a Mejarc title block whose ISO labels bind to the shared parameters already in the family.

03What changed

85 warnings. The largest area change was room 00.02, 64.985 to 64.959 m². The section now reads cleanly, and the sheet carries S2, SHARED, Portfolio issue and revision P01 on a numbering sequence called MEJ Preliminary P.

04What I would do next

Decide the last 71 overlaps wall by wall, then purge the old sample title block. The title block date prints 11/22/26; the next issue uses ISO 8601.
